# PaiChai Dev 26 Organization Profile

GitHub Organization `PaiChai-Dev26`의 공개 프로필과  
프로젝트 저장소에 공통으로 적용할 협업 문서를 관리하는 저장소입니다.

## Repository Structure

```text
.
├── profile/
│   └── README.md
├── docs/
│   ├── PROJECT_CYCLE.md
│   ├── PROJECT_START_CHECKLIST.md
│   └── TEAM_RULES.md
├── .github/
│   ├── ISSUE_TEMPLATE/
│   │   ├── task.yml
│   │   ├── idea.yml
│   │   ├── retrospective.yml
│   │   └── config.yml
│   └── PULL_REQUEST_TEMPLATE.md
├── CONTRIBUTING.md
└── README.md
```

## Purpose

- `profile/README.md`: 조직 공개 메인 프로필
- `docs/`: 팀의 프로젝트 운영 기준
- `.github/ISSUE_TEMPLATE/`: 작업·아이디어·회고 등록 양식
- `.github/PULL_REQUEST_TEMPLATE.md`: 공통 Pull Request 양식
- `CONTRIBUTING.md`: 팀원 공통 협업 방식

## Important

- 교수님 또는 연구실의 공식 승낙 전에는 Advisor나 공식 소속으로 표시하지 않습니다.
- 프로젝트가 확정되기 전에는 특정 공모전용 저장소를 만들지 않습니다.
- 역할은 고정 직무보다 실제 작업 단위로 나눕니다.
- 개인정보, 회사 자료와 비공개 연구자료를 업로드하지 않습니다.
